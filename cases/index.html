SYNTHETIC LAB BUILD

Enterprise request workflow

The problem. Requests cross multiple systems and lose context. Automated actions need a visible path back to their inputs and an explicit human decision.

The build. A browser-local state machine extracts fields, classifies a request, looks up a fictional account and creates a draft record. Known accounts can be validated; unknown accounts require rejection.

Evidence and limits. The interactive lab exposes structured state and an execution log. Automated tests cover every transition, input bounds and the approval guard. The API and data are mocked. No production savings are claimed.

PRIVATE PRODUCT EXPERIMENT

Technical interview coach

The problem. Software professionals need to explain technical decisions in English, using the requirements of an actual job description.

The build. Recovery of an existing Next.js prototype, with private access, PostgreSQL session budgets, optional content persistence and a written rehearsal mode. Voice uses a server-mediated WebRTC design.

Evidence and limits. Source, build and database tests are maintained privately. Written rehearsal is deterministic and produces no fluency scores. A bounded real OpenAI WebRTC session with synthetic desktop audio was verified. Physical Samsung device acceptance and human listening remain pending; no training effectiveness is claimed.
