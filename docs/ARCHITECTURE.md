# Santensor commercial site

Buildless static HTML, CSS and native JavaScript modules. No runtime backend is needed on GitHub Pages. English positioning follows the three required capability areas in order. The original assets and source history are preserved. The HTML has canonical metadata, a sitemap, accessible landmarks, visible keyboard focus and reduced-motion support. No external fonts, analytics, stock media or tracking scripts are used.

`/labs/` runs a browser-local, deterministic state machine with synthetic fixtures. It exposes field extraction, classification, fictional directory lookup, in-memory draft creation, owner assignment, a notification draft and explicit human validation. It sends no email and changes no external system. Unknown accounts cannot be approved. Text is rendered with textContent rather than injected as HTML.

`/cases/` documents the lab and private trainer honestly as experiments. No invented clients, metrics, certifications or business outcomes appear.

The public contact route is the existing enabled GitHub Issues channel for this repository. It requires GitHub login and is explicitly public; no email address was invented. No inquiry was sent by automation.

Local browser checks cover all routes, internal links, no overflow and axe WCAG A/AA at 390, 768 and 1440 pixels. This is automated accessibility coverage, not a complete human accessibility audit. Lighthouse results are simulated lab measurements, not production field data.
