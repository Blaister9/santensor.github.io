Portfolio — architecture and verification

A public static website with two independent rendering paths.

HTML and localized content are generated at build time. JavaScript mounts the simulator and continuous scene navigation. WebGL is optional; the 2.5D path uses original rendered images. Contact uses a confirmed mailto address.

Regression tests exercise five scenes, both languages, real keyboard events, recovery and historical snapshots. Automated axe checks examine generated pages. Emulation does not establish physical-device or screen-reader acceptance.

Portafolio — arquitectura y verificación

Sitio estático público con dos rutas de render independientes.

El HTML localizado se genera durante el build. JavaScript monta el simulador y la navegación continua. WebGL es opcional; la alternativa 2.5D usa renders originales. El contacto utiliza una dirección mailto confirmada.

Las regresiones recorren cinco escenas, ambos idiomas, teclado, recuperación e instantáneas históricas. Axe analiza las páginas generadas. La emulación no establece aceptación física ni con lector de pantalla.
